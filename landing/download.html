After you install

Three steps

  1. 01

    Open the app.

    Start Biorouter from Applications, the Start menu or your app launcher.

  2. 02

    Connect a model.

    Pick a provider on the Welcome screen, or later in Settings → Models. Llama Server, on the Local tab, needs no account or key. UCSF users pick Versa API Azure or Versa API Bedrock on the Institutional tab.

  3. 03

    Ask a question.

    Type in the message box and press Enter.

Command line and servers

The biorouter tool

The command line tool
ships with the app.

The first time you open the app, it offers to install the tool: press Install on the Biorouter CLI card. After that, biorouter works in any terminal.

On a Linux server, HPC node or container, install a command line only package instead. It holds the biorouter tool, the biorouterd daemon and the web interface, without the desktop app.

To install it yourself on macOS
/Applications/Biorouter.app/Contents/Resources/bin/biorouter setup-path
On Windows, use the Install card, or run resources\bin\biorouter.exe setup-path in the folder you unzipped.
Choose the model before you serve. A browser session cannot change it.
biorouter configure
Use Biorouter from a browser, then open the address it prints
biorouter serve
Check the setup and optional prerequisites
biorouter doctor

Requirements

What each build runs on

macOS

Apple silicon and Intel. Builds are signed with UCSF's Developer ID and notarized by Apple.

Windows

x64. The installer upgrades an existing install in place.

Linux

x86_64. The desktop packages need Debian 12, Ubuntu 22.04, Fedora or RHEL 9 or newer. Local models need Debian 12 or Ubuntu 22.04 or newer. The command line packages also run on Debian 11.
