About

Built at UCSF,

Inspirations

Biorouter's design was inspired by the agents below, and Block's Goose was a major influence.

  • Goose ↗

    Block's extensible agent, built around MCP.

  • Claude Code ↗

    Anthropic's coding agent for the terminal.

  • Codex CLI ↗

    OpenAI's coding agent that runs locally.

  • Gemini CLI ↗

    Google's Gemini agent for the terminal.

  • OpenHands ↗

    An open platform for coding agents.

  • Aider ↗

    Pair programming that commits to Git.

  • Cline ↗

    An autonomous coding agent in the editor.

  • OpenCode ↗

    An open source agent for many providers.

  • ForgeCode ↗

    A terminal agent that plans, then codes.
