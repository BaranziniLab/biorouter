Sep

Biorouter v1.91.1: Windows sockets stop leaking into child processes, and a steadier macOS extension start

On Windows, every network socket Biorouter opened was inherited by the programs it starts, so a port could stay taken after the app exited and the remote tunnel could not close cleanly. Every listener and connection is now non-inheritable, confirmed on a Windows machine, and a build check keeps it that way. On macOS, an extension started from inline Python could very occasionally be killed before it ran; it now starts the way every other extension does. The test suite also had a run of flaky failures fixed at their causes, so a red build now means something is broken.

Biorouter v1.90.0: every tool driven across providers, and a review run before the drive

Two campaigns landed in this minor release. Exercising all 419 tool and mode combinations in the running app found twenty-four issues: a knowledge base could wedge until restart because an abandoned transaction held its write lock, a tool call that asked for approval could hang forever, editing a .docx destroyed the images it already contained, and a Windows path bug made every existing raw file read as absent. A programming review run before the drive closed a set of security defects, among them a schedule id that went straight into a path join and wrote outside the managed directory, an MCP extension that could read the daemon secret out of a proxy frame URL, and a private chat that could write into a new public conversation with no crossing approval.

Aug

Biorouter v1.89.0: privacy tiers, Workspace Control, and several knowledge bases per chat

This is the release where the app learns the difference between a model your institution has an agreement with and one it does not, and refuses to send your private work to the wrong one. Every model carries a privacy tier and an institution, and so does every chat, knowledge base and clinical connector. A chat that has touched PHI will not run on a commercial model, and its history will not reach one through recall, ingest, branching or summarisation. Alongside it, Workspace Control lets Biorouter work across your conversations instead of only inside one, and turns a delegated subagent into a tab you can read, steer and stop. A chat can use several knowledge bases at once with one marked primary, machine-wide memory is no longer injected into every chat’s system prompt, and a message typed while Biorouter is working is no longer thrown away. Built-in skills moved out of the Skills count into their own Contexts section.

Jul

Biorouter v1.88.5: Fully-Automatic mode, a hardened permission engine, and desktop polish

Biorouter v1.88.5 introduces Fully-Automatic mode, which gives the agent broad autonomy over ordinary file work while still stopping to ask before a small, well-defined set of sensitive system operations (writes under system directories, SSH keys, keychains, launchd and login items, and browser credential stores), so long unattended runs keep moving without a prompt on every edit. The permission engine behind it was hardened: a routine 2>/dev/null redirect and other benign character devices are no longer misread as protected-directory writes that stall autonomous agents, sensitive writes hidden inside shell command lines and code bodies are detected, and the text editor's project jail is relaxed in Auto mode without loosening the catastrophic-path denylist. The desktop gains grabbable split dividers, a split cap raised from four to six panes, per-pane terminals that open in the session's own folder, a composer toolbar that collapses behind a plus button when the row is too narrow, chat names that stay in sync across recents, history, tabs, and diverged branches, and drag-to-reorder tabs that track the pointer. Artifact preview now surfaces files created inside code execution, renders images and links in markdown, and no longer opens the wrong same-named folder. Chat reliability improves too: a rapid double-submit no longer appends a duplicate bubble, a transient backend blip degrades to an inline retryable error instead of a fatal session card, and soft interrupt and hard stop are acknowledged immediately. Theme families are now generated from one definition file each, adding a UCSF-teal Alma Mater and a JupyterLab-inspired Roche Limit family, with structured per-tool-result logging for observability. Existing settings, sessions, providers, extensions, skills, workflows, applications, knowledge bases, and usage history remain compatible.

Inspirations

Biorouter is an independent project that started from its own source code. The agents below influenced its design, Goose most of all, and it also draws on many open source libraries.

Goose CLI and desktop agent for full developer workflows (Block). A major inspiration for Biorouter's design.
Claude Code Anthropic's agentic coding tool for the terminal and IDE.
Codex CLI OpenAI's open source coding agent that runs in the terminal.
Gemini CLI Google's open source AI agent for the terminal.
OpenHands Open source platform for autonomous software development agents.
Aider Open source coding agent for the terminal that works with Git.
Cline Open source interactive CLI coding agent.
OpenCode Open source coding agent that supports multiple sessions and providers.
ForgeCode Terminal AI coding assistant for task planning and code generation.
