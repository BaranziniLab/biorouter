# Baseten theme

> **What this is.** The reference for Baseten, the fourth theme family, which applies Baseten's
> brand system (palette, typography and corner rules) to the desktop app: what the family owns,
> what it shares with the others, and where each brand rule is implemented.
> **Status:** Proposed. Implemented on the `feat/baseten-brand` branch on 2026-11-02, where it
> is the default family for anyone who has not picked one.
> **Audience:** developers working on theme families, and anyone reviewing the branding change.

## What the family owns

The family is one file, [`ui/desktop/themes/baseten.theme.mjs`](../../../ui/desktop/themes/baseten.theme.mjs);
`npm run themes` generates its CSS block, syntax and terminal palettes and picker entry from it.
Like every family, it varies only ink, accent, status hues and the heatmap. Its surfaces, greys,
borders and avatar hues are the shared neutral set, which `themeNeutrals.test.ts` holds equal.

| Role | Light | Dark | Why |
|---|---|---|---|
| Accent fill (primary button, switch on) | `#19e76e` with `#000000` ink | `#19e76e` with `#000000` ink | Brand green is a fill colour, so it carries black text |
| Accent text (links) | `#007a2b` | `#7df2ad` | The base green is never small text; a deeper green holds 4.5:1 on white |
| Accent edge and rail | `#009735` | `#19e76e` | Brand dark green, 3:1 on light grounds |
| Ink / muted ink | `#1c1c1b` / `#575d56` | `#f3f6f2` / `#b4bcb2` | Brand black and dark grey; the ink is a hair off pure black so the 5% hover wash stays visible over a switch track |
| Success | `#007a2b` | `#5cf096` | Brand green family |
| Info | `#0065ad` | `#6dbbff` | Brand dark blue |
| Danger, warning | shared hues | shared hues | The brand defines no red or yellow |
| Heatmap | light green to dark green | dark green to brand green | One accent hue, as the brand asks |
| Syntax | green, blue and pink families only | the same, lightened | Six distinct shades, so CSV columns stay apart |

## What lives in `main.css`

The theme contract carries colour only, so the brand's type and shape rules are authored under
`:root[data-theme='baseten']`, right after the generated region:

- **Body face.** `--font-body` names Beausite Classic first, then Hanken Grotesk. Beausite is
  proprietary and not bundled; Hanken Grotesk (SIL OFL) is bundled in `ui/desktop/src/assets/fonts/`.
  Tracking is -2% everywhere, and `text-title` is re-pointed to match.
- **Mono roles.** Buttons (`[data-slot='button']`), chips (`text-chip`), eyebrows (`text-caps`)
  and numbers (`tabular-nums`, `.br-stat-value`) use Geist Mono (SIL OFL, bundled) at +6% tracking,
  uppercase except for numbers. Code and the terminal keep the system `--font-mono`, which xterm must
  match exactly.
- **Corners.** Every radius on the ladder is 2px. `--radius-full` stays for status dots, the switch
  and avatars.

## Known limits

- The brand's green-tinted greys (`#e3eae1`, `#c7d4c4`) are not used, because family neutrals are
  shared by rule. Using them would mean adding those tokens to the per-family allowlist in
  `themeNeutrals.test.ts`.
- The boot splash keeps the Biorouter mark inks, as it does in every family.
- Uppercase mono button labels are wider than sentence-case Arial. A button whose label is clipped
  at narrow widths should be fixed in the button, not by turning the rule off.
- Figures from the Auto Visualiser are generated by Rust templates and are not restyled.
