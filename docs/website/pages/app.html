The desktop app

The app is where you chat with a model, watch the agent work and read what it makes.

The window

The sidebar runs down the left. The rest of the window shows the page you opened. In a chat, tabs run across the top, the conversation fills the middle and the composer sits at the bottom.

Files, figures and apps the agent makes open in a side panel on the right. In the conversation each one is a card; choose it to open it in the panel. In a live chat the panel opens on the newest one by itself. A terminal can open below the conversation.

Drag the sidebar's edge to resize it, or press Cmd+B to hide and show it. Shortcuts on this page are shown for macOS; see Keyboard shortcuts.

The sidebar

From top to bottom:

  • Home. A greeting, a heatmap of your recent activity and a composer. Typing there starts a new chat.
  • New chat. An empty chat in a new tab.
  • Crew. Your lab's shared workspace: channels, files and agent tasks. See Crew.
  • Components. A group holding the six rows below. It starts collapsed and stays the way you last left it.
    • Workflows. Saved recipes that start a chat with the same instructions, tools and model. See Workflows and scheduling.
    • Scheduler. Workflows set to run on a schedule, with each one's timing and last run.
    • Extensions. The tool servers the agent can use, each with an on and off switch, plus the BAAM marketplace and custom extensions. See Extensions and skills.
    • Skills. Instruction sets the agent loads when a task calls for one.
    • Knowledge. Knowledge bases the agent writes and reads. See Knowledge bases.
    • Built apps. Apps the agent built for you. This is the only place to delete one. See Built apps.
  • Recents. Your recent chats, grouped by day. A running chat shows an indicator. See all opens Chat history.
  • Settings. Pinned at the bottom. See Settings.

Chat and the composer

Type a request and press Enter. Shift+Enter starts a new line. Type / to pick a command, workflow, skill, knowledge base or extension, or @ to mention a file or folder. Paste or drag files and images onto the composer to attach them.

To report a Biorouter bug, type /bug and a space. It becomes a Report a bug chip; describe what went wrong after it, and the agent drafts a GitHub issue for you to approve.

The composer has three rows.

  • Above the text box. On the left, the working folder the agent reads and writes in. It is fixed once you send the first message. On the right, the extensions, skills and knowledge bases this chat uses, each with a count. Changes there apply to this chat only.
  • In the box. Your message, and Send, the arrow at the right. While the agent works and the box is empty, Send becomes Stop.
  • Below the text box. On the left, reasoning effort, which sets how long the model thinks before it answers, then the model this chat runs on (see Switching models). On the right, context shows how full the context window is. Its popover compacts the chat now, or sets when Biorouter compacts it on its own. Cost shows the estimated spend so far; turn it off in Settings → App → Appearance.

In a narrow pane, reasoning effort, context and cost fold into one + button, Chat tools and settings. The model stays visible.

While the agent works

Each tool call is one line in the conversation; choose it to see the arguments and the result. Messages you send meanwhile wait in a queue. Add now, or Cmd+Enter, adds a message to the running turn without stopping it. Stop & send stops the turn and sends the message as a new one. The agent loop explains how a turn runs.

Shell code blocks in a reply carry a Run button that sends the command to the terminal below the conversation.

Working with messages

  • Copy is on every message.
  • Edit on your own message offers Edit in place, which changes it in this chat, or Diverge, which starts a new chat from the edited message.
  • Diverge on a reply opens a new window holding a new chat with the full history up to that point. The original stays as it was.
  • Select text in a reply, right click, and choose Ask about it or Quote it to put the passage in the composer as a quotation.

Switching models

  1. Open the model chip Choose the model name under the text box, then Change model.
  2. Pick a provider and a model Then choose Select model. The next turn uses it; the conversation so far is unchanged.

The change applies to this chat only. Tick Also use for new chats to make it the default too. Settings → Models → Switch models sets the model new chats start on, and existing chats keep their own. A private chat accepts only private models. See Private and public.

Tabs and split panes

Every chat is a tab. Open one with Cmd+T, close it with Cmd+W, and move between tabs with Ctrl+Tab and Ctrl+Shift+Tab. Drag a tab to reorder it. Opening a chat that is already open switches to its tab. Drag a tab out of the window to give it a window of its own, or onto another window's tabs to move it there.

To split, drag a tab to the left, right, top or bottom edge of a pane. Dropping it in the middle of a pane moves it into that pane's tabs instead. A window holds up to six panes. Drag the line between two panes to resize them. Each pane has its own tabs, and each chat keeps its own model, folder and extensions, so you can watch several agents work at once.

The terminal

Choose the terminal icon at the top right of a chat (Open terminal) to open a terminal below the conversation. It starts in the chat's working folder. Each tab has its own terminal, and a hidden terminal's shell keeps running until you close its tab. + adds another terminal; Cmd+T does the same while the terminal has focus.

History

Chat history lists every chat, grouped by day. Open it with See all under Recents or with Cmd+2, and search it with Cmd+F. Choose a chat to reopen it in a tab.

Each row can export or delete its chat, and a private chat's row offers Make this chat public, which asks you to confirm. Import chat brings in a chat someone exported. Show subagent runs adds the chats that subagents ran. Chats live in a local SQLite file; see Configuration.

Settings

Settings has three tabs.

  • Models. The current model, with Switch models and Configure providers. Local Model Inventory lists the local models you have and can download, and deletes ones you no longer need. Reset clears the selected provider and model.
  • Chat. Mode sets how much the agent does without asking: Autonomous, Manual, Smart or Chat only (see Security). Response styles picks Detailed or Concise answers. Capabilities sets the built-in abilities new chats start with. The tab also holds Memory, Contexts (skills that ship with Biorouter), App SDK, Editor and Project hints (.biorouterhints).
  • App. Configuration edits the settings file. Privacy holds the private and public protection, which is on by default. Workspace can stop agents from opening tabs on their own. Appearance covers notifications, the menu bar icon (and the Dock icon on macOS), prevent sleep and cost tracking. Palette, Mode and Font size set how the app looks. Usage appears while cost tracking is on. Then come Reset, Help & Feedback and Updates.

Menu bar and tray

The menu bar repeats the sidebar and adds a few things of its own.

  • Biorouter. On macOS only: Settings, Check for Updates, Check for Dependencies, Check for Extension Updates.
  • Go. Home, New Chat, History, Workflows, Scheduler, Extensions, Skills.
  • File. New Chat, New Window, Open Directory, Recent Directories, Close Tab, Close Window, Focus Biorouter Window.
  • Edit. The usual editing items and Find.
  • Extensions. Install a .brxt file, browse BAAM, add a custom extension, check for extension updates.
  • Providers. Configure Providers, Switch Model, Reset Provider.
  • View. Light, Dark or System mode, zoom and full screen.
  • Help. These docs, Report a Bug, Request a Feature.
  • Window. Always on Top.

Settings → App → Appearance → Menu bar icon shows or hides the tray icon (the menu bar icon on macOS). It is on by default. On macOS and Windows, clicking the icon brings the window forward. Its menu holds Home, New Chat, Settings, Extensions, Skills, Check for Updates and Quit.
