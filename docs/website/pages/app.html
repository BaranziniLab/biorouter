The desktop app

The app is where you chat with a model, watch the agent work and read what it makes.

The window

The sidebar runs down the left. The rest of the window shows the page you opened. In a chat, tabs run across the top, the chat fills the middle and the composer sits at the bottom. In a wide window the chat summary sits at the right of the chat.

Files, figures and apps the agent makes open in a side panel on the right. In the conversation each one is a card; choose it to open it in the panel. In a live chat the panel opens on the newest one by itself. A terminal can open below the conversation.

Drag the sidebar's edge to resize it, or press Cmd+B to hide and show it. Shortcuts on this page are shown for macOS; see Keyboard shortcuts.

The sidebar

From top to bottom:

  • Home. A greeting, a card of your recent usage and a composer. The card's Overview tab shows chats, messages, tokens, active days, your streak and your favorite model, with a heatmap of the days you used Biorouter. Its Models tab shows usage by model. Choose 1y, 30d or 7d to change the period. Typing in the composer starts a new chat.
  • New chat. An empty chat in a new tab.
  • Crew. Your lab's shared workspace: channels, files and agent tasks. See Crew.
  • Components. A group holding the seven rows below. It starts collapsed and stays the way you last left it; it opens once by itself after you install a speech model.
    • Workflows. Saved recipes that start a chat with the same instructions, tools and model. See Workflows and scheduling.
    • Scheduler. Workflows set to run on a schedule, with each one's timing and last run.
    • Extensions. The tool servers the agent can use, each with an on and off switch, plus the BAAM marketplace and custom extensions. See Extensions and skills.
    • Skills. Instruction sets the agent loads when a task calls for one.
    • Knowledge. Knowledge bases the agent writes and reads. See Knowledge bases.
    • Dictionary. The words dictation should spell your way. See Dictation.
    • Applications. Applications the agent built for you. This is the only place to delete one. See Applications.
  • Chats. Your chats, one row each. A running chat shows an indicator, and a private chat's icon carries a small lock. Chats that Crew, a schedule, a subagent or an application started, and chats you diverged, each have their own icon. The View options menu in the header sets Group by (Date, Folder or None) and Sort by (Last activity, Created or Name). By default chats sit under Today, Yesterday, Previous 7 days, Previous 30 days and then a heading for each month. Grouped by folder, each folder has a + that opens a new chat window in it. All chats opens Chat history.
  • Settings. Pinned at the bottom. When an update is ready, an update row appears above it. See Settings.

Right click a chat, or choose ⋯ on its row, for Rename, Open in new tab, Open in new window, Diverge, Export…, Copy chat ID and Delete chat…. Rename edits the title in the row. On a focused row, F2 does the same.

Chat and the composer

Type a request and press Enter. Shift+Enter starts a new line. Type / to pick a command, workflow, skill, knowledge base or extension, or @ to mention a file or folder. Paste or drag files and images onto the composer to attach them.

To report a Biorouter bug, type /bug and a space. It becomes a Report a bug chip; describe what went wrong after it, and the agent drafts a GitHub issue for you to approve.

Next release. The one-line composer and the cards under it, the chat summary's sections, and subagents and decision models below arrive in the next release. In the current release the Tools chip and the model chip sit inside the card.

The composer is one card with a line under it.

  • In the card. On one line: the +, your message, the microphone and Send, the arrow. Attachments sit above the text, and the text grows upward as you type. While the agent works and the box is empty, Send becomes Stop.
  • The + popover. It opens on Add: Attach files…, Mention, Commands and Decision models and monitors… (see Subagents and decision models). Extensions, Skills and Knowledge along its bottom edge each show a list with a switch on every row, and a line above the list says where a change applies: this chat, or on Home the next one. Extensions folds the capabilities that ship with Biorouter under Built-in capabilities, and Skills folds the shipped skills under Built-in contexts. Point at the + to see how many of each the chat uses.
  • Under the card. On the left, the working folder the agent reads and writes in. On the right, the model chip, then a ring that shows how much of the context window is left, then the estimated cost of the chat so far. A decision chat has no ring. On Home the line shows the folder and the model.
  • The model chip. It names the model this chat runs on. Its menu shows the provider and whether the model is private, sets Effort (Quick, Normal or Deep), which is how long the model thinks before it answers, and offers Change model…. See Switching models.

Point at the folder, the ring or the cost to see a card about it, and click to keep the card open. Esc or a click elsewhere closes it.

  • Folder. The full path and, while the chat is empty, Choose folder…; once you send the first message the chat keeps its folder. Below it are the other folders the chat may use, each with Revoke. Cmd-click the folder to open it in Finder, or Ctrl-click on Windows and Linux; a biorouter serve browser cannot.
  • Ring. How much is left and used, and a bar whose marker sets when Biorouter compacts the chat on its own. Compact chat compacts it now. When the chat can call more than 60 tools, Review extensions appears beside it.
  • Cost. What the chat used, and a limit for it in dollars or tokens. Until you set one, the default from Settings → App → Usage applies. The limit counts the chat and the subagents it starts, and a chat that reaches it pauses before its next model request. Settings → App → General → Show costs hides the dollar figures, not the limit.

The chat summary

Once a chat has started, the chat summary shows these sections from top to bottom.

  • To do. The agent's to do items, each marked as it finishes.
  • Agents or Plan. A chat with subagents shows Agents. When the agent sets a phase plan, Plan takes its place: each phase with its agents, and a mark on a phase that has a gate. Plan starts open, and To do then starts closed.
  • Decisions. Once the chat has monitors or decision calls, one row for each source.
  • This chat. Closed at first, with the chat's tokens in its heading, such as "392k tokens". Open it for the model, the privacy (while the private and public protection is on), tool calls, tokens, artifacts and the lines of code the chat added and removed. In a subagent's own chat it reads Subagent chat.

Below them, Make workflow turns the chat into a workflow (it reads Workflow once the chat has one), and Diagnostics produces a bundle for a bug report. In a wide window the summary sits at the right of the chat and moves the chat a little to the left. When there is not room, the summary button at the top right of the chat opens it as a popover instead.

While the agent works

Each tool call is one line in the chat, with an icon for the kind of tool; choose it to see the arguments and the result. Messages you send meanwhile wait in a Queued list above the text box. Each one has buttons to add it to the running turn without stopping it (Cmd+Enter does the same), to stop the turn and send it as a new one, to edit it and to remove it. A failed turn shows its error once, with Retry when trying again can help. The agent loop explains how a turn runs.

Shell code blocks in a reply carry a Run button that sends the command to the terminal below the conversation.

Working with messages

  • Copy is on every message.
  • Edit on your own message opens it in an editor. Save changes the message and continues the chat from there. Save as new chat starts a new chat from the edited message and leaves this one as it was.
  • Diverge on a reply opens a new window holding a new chat with the full history up to that point. The original stays as it was.
  • Select text in a reply, right click, and choose Ask about it or Quote it to put the passage in the composer as a quotation.

Subagents and decision models

Subagents the agent starts run in the background and are listed in the chat summary. Point at one to see what it is doing, or choose Open in a tab. Settings → App → General → Open subagent tabs automatically, off by default, opens each one in a tab as it starts, unless Never open tabs automatically is on. Subagents run on Settings → Models → Default worker model unless the agent names another model; it reads "Same as the chat’s model" until you choose one, and a private chat never hands work to a public worker model. It replaces lead and worker mode, and an older lead and worker setup moves over once. See The agent loop.

Decision models are optional, fast models that answer a fixed question, such as yes or no, with a probability for every answer. They run on Baseten or as a local Ollama model, and one can also be a chat's own model, which makes it a decision chat. Decision models and monitors… in the + opens the Monitors dialog, where you choose the chat's decision model and add monitors that check the chat as it runs and notify you, tell the agent or stop the turn. The summary's Decisions section has one row for each monitor, one for the agent's checks and one for a decision chat's answers; choose a row to open its decision history. A chat is as private as the least private model it uses, decision models included, so a public decision model makes the chat public. See Private and public.

Dictation

Next release. Local dictation is not in the current release. It arrives in the next one.

Dictation turns your speech into text in the composer. It runs on this computer with a speech model you install once, and it spells your own terms the way your dictionary does. Nothing is sent until you press Send.

  1. Install a speech model Choose the microphone left of Send. The first time, it offers Install and Not now, and nothing downloads until you choose Install. Biorouter picks the model for your computer: whisper-large-v3-turbo-q5_0 (574 MB) on Apple silicon, whisper-small.en-q8_0 (264 MB) elsewhere. It comes from the Baranzini Lab's own repository on GitHub and is checked before use. Settings → Models → Speech models installs, switches and removes models and shows the folder they live in.
  2. Dictate Choose the microphone, or press Shift+Cmd+D: a tap starts and stops a recording, and holding it records while you hold. The first time, macOS asks for the microphone. Enter stops and puts the text at the cursor; Esc throws the recording away. One Cmd+Z takes the dictated words back out.
  3. Check and send Read the text, fix anything, then press Enter to send. When you correct a dictated word the same way twice, Biorouter learns it for a term in your dictionary.

The same microphone sits in the message editor, and in Crew's channel composer and Ask my agent box, where nothing is posted until you press Send.

Your dictionary

Dictionary, in the sidebar's Components group, lists the words dictation should spell your way, such as UCSF or EPAS1. Add one there with Add a term…, or right click a word in a chat and choose Add to Biorouter dictionary…. A term you add from a private chat is private unless you untick Only in private chats: it shapes dictation only into chats on private models, and never into a chat on another institution's model. See Private and public.

At the first install, Suggest dictionary words from my chats lets the agent add terms in new chats. Agent's terms on the Dictionary page sets what happens then. By default, Add when I ask, suggest otherwise, a term goes live at once only when you asked for it or answered the agent's offer of it, and anything else waits under Suggested. The other choices are Wait for my review and Add without asking. In the chat, the agent's line has Keep and Undo for each term it added; on the Dictionary page such a term has Keep and Remove.

Suggest words from my messages, a switch on the Dictionary page and in Settings → Models → Speech models, is off until you turn it on. It suggests terms such as EPAS1 or UCSF from what you type in chats on public models, once a word shows up in two different chats, or more after you dismiss most suggestions. A chat on a private model suggests nothing, and what it reads stays on this computer. With the switch on, Find words in my recent chats reads your recent chats once. Keep or Dismiss each suggestion, or choose Review all…; a dismissed word is not suggested again. The page groups terms under Suggested, Added by the agent, Added by you, From your chats and Imported. In a terminal chat, /dictionary scan and /dictionary review do the same.

In the terminal, the browser and other apps

  • Terminal. Ctrl+T or /dictate in a chat, and biorouter dictate anywhere else. See Dictate.
  • Browser access. A biorouter serve browser has the same microphone. The audio is transcribed on the server, and models install there. Browsers offer the microphone only on localhost or an HTTPS address. See Browser access.
  • Other apps. Dictate to clipboard in the tray menu records and copies the text for you to paste anywhere. It starts only after you turn on Dictate into other apps in Settings → Models → Speech models, where you can also choose a keyboard shortcut for it; until then the tray item opens that setting. The tray item is there only while Settings → App → General → Show in menu bar is on; the shortcut works without it. On Windows and Linux both work only while a Biorouter window is open, minimized included, because closing the last window quits the app there. Include my private terms, beside it in the tray menu, lets your private terms shape one recording after a warning. It is greyed out until Dictate into other apps is on, and where private terms cannot be used. The shortcut always uses public terms only. GNOME on Wayland lets no app set a shortcut that works in other apps, so there use the tray item, which GNOME shows with the AppIndicator extension.
  • Applications. In the preview of an application the agent built, click into one of its text fields and choose Dictate into this application, which appears while a field has focus. It works whether or not Dictate into other apps is on.

Audio is never saved, and once a model is installed dictation needs no network. On a computer with no network, run biorouter dictation urls on a connected one, carry the files over and run biorouter dictation install --from with their folder. Processors without AVX2 cannot run local dictation, and Biorouter says so before any download.

Switching models

  1. Open the model chip Choose the model name on the line under the composer, the first item on the right, then Change model….
  2. Pick a provider and a model Then choose Select model. The next turn uses it; the conversation so far is unchanged.

The change applies to this chat only. Tick Also use for new chats to make it the default too. Settings → Models → Default model → Change… sets the model new chats start on, and existing chats keep their own. A private chat accepts only private models. See Private and public.

Tabs and split panes

Every chat is a tab. Open one with Cmd+T, close it with Cmd+W, and move between tabs with Ctrl+Tab and Ctrl+Shift+Tab. Drag a tab to reorder it. Opening a chat that is already open switches to its tab. Drag a tab out of the window to give it a window of its own, or onto another window's tabs to move it there. Right click a tab, or press F2 on it, to rename its chat. When there are more tabs than fit, a menu lists them all, with a filter once there are eight or more.

To split, drag a tab to the left, right, top or bottom edge of a pane. Dropping it in the middle of a pane moves it into that pane's tabs instead. A window holds up to six panes. Drag the line between two panes to resize them. Each pane has its own tabs, and each chat keeps its own model, folder and extensions, so you can watch several agents work at once.

The terminal

Choose the terminal icon at the top right of a chat (Open terminal) to open a terminal below the conversation. It starts in the chat's working folder. Each tab has its own terminal, and a hidden terminal's shell keeps running until you close its tab. + adds another terminal; Cmd+T does the same while the terminal has focus.

History

Chat history lists every chat under Today, Yesterday, Previous 7 days, Previous 30 days and then by month. Open it with the All chats button in the Chats header or with Cmd+2, and search it with Cmd+F. Choose a chat to reopen it in a tab.

Point at a row to Rename its chat, or open its menu for Diverge, Export…, Copy chat ID and Delete chat…. A private chat's menu also offers Make this chat public, which asks you to confirm. Import chat brings in a chat someone exported. Show subagent runs adds the chats that subagents ran. Chats live in a local SQLite file; see Configuration.

Settings

Settings has three tabs.

  • Models. Default model shows the model new chats start on, with Change…. Under it, Default worker model, in the next release, sets the model subagents use unless the agent names another; it reads "Same as the chat’s model" until you choose one. Crew tasks sets the model for agent tasks in Crew; it reads "Same as new chats" until you choose one. Then come the providers, with Manage…. Local models lists the local models you have and can install, and deletes ones you no longer need. Speech models, which arrives with local dictation, installs, switches and removes speech models. The Danger zone has Reset…, which clears the provider and model new chats start on.
  • Chat. Approvals sets how much the agent does without asking: Autonomous, Manual, Smart or Chat only (see Security), the per-tool permissions and the maximum turns. Display decides whether tool calls start expanded or collapsed and turns spellcheck on or off. Capabilities sets the built-in abilities new chats start with. The tab also holds Memory, Contexts (skills that ship with Biorouter), App SDK and Project hints (.biorouterhints).
  • App. Configuration edits the settings file. Privacy holds the private and public protection, which is on by default. General covers notifications, the menu bar icon (and the Dock icon on macOS), prevent sleep, Never open tabs automatically (an agent that opens a chat or starts a subagent notifies you instead), Open subagent tabs automatically (off by default; next release) and Show costs. Appearance sets the theme, the color palette and the text size. Usage shows this month's billed tokens, estimated cost and turns by day and model; with Show costs off it drops the dollar figures. In the next release it adds a Decision models line and Limits: a Monthly limit and a Default limit per chat, each "No limit" until you set one in dollars or tokens. At the monthly limit every chat stops before its next model request until you raise or remove it; the month resets on the 1st, local time. A biorouter serve browser shows a note pointing to the desktop app in place of the report and limits. Then come About (version, updates and feedback), Server (connect to a Biorouter server running elsewhere) and the Danger zone (Reset data).

Menu bar and tray

The menu bar repeats the sidebar and adds a few things of its own.

  • Biorouter. On macOS only: Settings, Check for Updates, Check for Dependencies, Check for Extension Updates.
  • Go. Home, New Chat, History, Workflows, Scheduler, Extensions, Skills.
  • File. New Chat, New Window, Open Directory, Recent Directories, Close Tab, Close Window, Focus Biorouter Window.
  • Edit. The usual editing items and Find.
  • Extensions. Install a .brxt file, browse BAAM, add a custom extension, check for extension updates.
  • Providers. Configure Providers, Switch Model, Reset Provider.
  • View. Light, Dark or System mode, zoom and full screen.
  • Help. These docs, Report a Bug, Request a Feature.
  • Window. Always on Top.

Settings → App → General → Show in menu bar shows or hides the tray icon (the menu bar icon on macOS). It is on by default. On macOS and Windows, clicking the icon brings the window forward. Its menu holds Update Available… while an update is ready, then Dictate to clipboard and Include my private terms, which arrive with local dictation (see Other apps), then Home, New Chat, Settings, Extensions, Skills, Check for Updates and Quit. During a recording, Stop and copy and Cancel take the place of the two dictation items.
