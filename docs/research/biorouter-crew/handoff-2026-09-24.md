3. All live agent QA uses private Versa `versa_azure` / `gpt-5.5-2026-04-24`. No local Qwen, Ollama or llama models.
4. New scope, Crew GUI redesign: clean, minimal, elegant and Slack-like, consistent with BioRouter's design system (`design.md`, theme tokens) and the rest of the chat UI. Layered navigation (dropdown menus rather than flat rows of equal-weight buttons); progressive disclosure (only required fields visible, optional and advanced options behind an Advanced disclosure); obvious affordances (dropdowns look like dropdowns, lists like lists, anything to share in a code-block-style box with one-click Copy); far less explanatory text and disclaimer copy, keeping only what has immediate consequences; good animation and transitions; usable by a complete novice. Fresh agents driving the real app act as novice UI/UX critics, and the design iterates until they succeed unaided.
5. New scope, human-readable identity and naming: people appear by display name or at least `@username` (unique per SSH server), never by long machine IDs (UUIDs, hex keys, principal IDs). Teams get unique, memorable names per workspace instead of machine strings, and setup uses these names (for example, invite `@bob` instead of copying an opaque token). Machine IDs remain internal, optionally behind a Copy ID or details affordance. Any protocol change must preserve kernel-derived identity, UID-recycling protections and every existing security property, with adversarial regressions.
6. Keep the [implementation plan](implementation-plan.md) and this handoff updated in real time whenever a decision changes execution, so all agents stay current.

Requirements 4 and 5 are recorded as acceptance requirements in [plan §16](implementation-plan.md#16-resumed-scope-gui-redesign-and-human-readable-identity-2026-09-23).
