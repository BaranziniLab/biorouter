# Biorouter v1.91.2

This patch release brings the changes merged since v1.91.1 into the desktop, CLI,
and packaged apps. It improves chat navigation and reading, tightens Biorouter
Copilot's controls, and addresses Windows console flashes.

## Biorouter Copilot

- The status banner appears only in a conversation that has actually requested
  Copilot. A completed banner can be dismissed and stays dismissed when you
  switch conversations. A new request brings it back. During active control,
  dismissing the details keeps Stop available.
- When macOS permissions are missing, setup names the exact helper executable
  that needs access. This matters when installed and development copies have
  separate Screen Recording grants.
- Prompts and slash-command guidance use Biorouter Copilot's current name. The
  compact `/ext:BiorouterCopilot` command resolves to the existing capability;
  stored settings and tool identities remain compatible.
- The app now validates the native helper against the same patch pin used to
  build it, so the updated helper passes compatibility checks instead of being
  rejected as an incompatible runtime.

## Windows

- Desktop and daemon child processes now suppress unwanted console windows.
  The Copilot helper also hides the PowerShell process it starts for Windows
  accessibility actions. Windows checks cover the child process directly.
- The packaged daemon is tested for releasing its listening port even when a
  child it started remains alive.
- A concurrent delete in the memory store no longer makes a legitimate write
  look like an attempted path escape.

## Chat and interface

- Selected text in answers and document previews can be quoted into the chat
  composer. Drafts and quotes survive switching between existing chat tabs.
- The slash picker includes extensions active in the current conversation,
  and terminal command routing follows the same catalog. Branch actions are
  called Diverge. Reserved workflow names cannot intercept built-in commands.
- Markdown, tables, tool logs, and chat tabs are easier to read. Standard,
  Large, and Larger font settings scale shared content and controls while
  keeping the app's window layout stable.
- The README now leads with model choice, public and private separation, and
  biomedical research, with the relevant privacy disclosures retained.

## Release checks

The release build uses the Windows and Linux Copilot helpers from their own
packaging jobs and builds only the Mac helpers locally. The Windows package
and native helper are checked on Windows before publication.
