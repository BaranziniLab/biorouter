# Biorouter v1.90.5

This patch improves chat reliability, responsive file previews, and the privacy checks around scheduled work.

## Chats keep their place and finish correctly

- Closing a tab during a reply no longer leaves its chat stuck running. Reopening shows the completed answer and an idle composer. Observed chats reconnect when reopened.
- Streamed text retains repeated characters and tokens at chunk boundaries while replayed events remain deduplicated.
- Mid-turn steering stays queued until the active turn consumes it. Retries keep their original turn and message identity, and cancellation preserves accepted text without duplicating it. Unconfirmed text remains available to copy or send again.
- Queued follow-up messages survive tab switches and send once. Send in a split view submits that pane's composer.
- Subagent tabs keep their Bot icon across navigation and reload. Chats with an unresolved privacy tier no longer briefly appear public.

## Responsive previews with restrained motion

- The preview adapts between a side panel and a vertical layout in narrow panes while retaining its mounted content.
- Opening, closing, and switching layouts use short slide-and-fade transitions. A small resize buffer prevents repeated flips near the threshold, and Reduce Motion disables animation.
- Markdown, CSV/TSV, source code, logs, and notebooks use the same paper surface as charts and a consistent reading measure.
- Syntax highlighting covers more source formats, raw tables, and log levels. Line numbers remain readable while scrolling sideways.
- Text selection uses translucent Biorouter orange across theme families.
- Native window backgrounds match the app during resizing, preventing exposed unpainted areas.
- Browser previews explain when image capture requires the desktop app instead of throwing a bridge error.

## Scheduled work follows the caller's reach

- Schedule writes and `/schedule` and `/loop` management commands use the same definition of private work. A public chat cannot run, pause, resume, or remove private work.
- Restoring a chat without a saved model cannot silently bind a private default without the required standing.
- Scheduled runs recheck their authority when starting; refused runs do not consume the configured run limit. Run requests report admission honestly.
- Reset requires a proven user action, and session change feeds apply the same visibility rules as session listings.

## Extension catalog

- Adds Helena Bioinformatics' Folklore Clinical Variant Interpretation MCP v1.4.0 to BAAM as a public, read-only variant evidence and literature extension.
